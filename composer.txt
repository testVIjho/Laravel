Simple-aa sonna, Laravel project-ku thevaiyana PHP packages/libraries-ah install, update, manage panna use panra tool.

6. vendor folder na enna?

Composer packages install pannumbodhu:

vendor/folder create aagum.
Adhukkulla Composer install panna packages irukkum.
